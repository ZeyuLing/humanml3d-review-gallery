# HumanML3D Text-to-Motion Comparison

This storage-limited qualitative gallery includes **all 4,042 samples** and eight selected comparison entries:

1. GT
2. AnimateCanvas 0.46B
3. HYMotion 0.46B
4. GoToZero 7B
5. MotionGPT3
6. KIMODO

The subset prioritizes initialization comparisons, the reviewer-discussed KIMODO comparison, and manuscript T2M baselines. The original gallery contained 28 entries; this selection reduces hosting storage. No samples were removed or selected based on output quality. Quantitative results in the manuscript are unchanged.

Search by caption or sample ID, or use Random sample to sample the current search results. Playback defaults to real-time 1× speed; use the shared timeline and speed selector to inspect motion. Drag to orbit and scroll over a model to zoom.

Motion payloads, SMPL shape corrections, and constant per-sequence floor alignment are retained. No motion smoothing was added. All runtime resources are local. Open index.html in the Anonymous GitHub website view. Third-party library license notices are retained.
