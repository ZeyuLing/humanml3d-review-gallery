# HumanML3D Text-to-Motion Comparison

Interactive qualitative comparisons across all 4,042 samples and 28 methods from the source viewer. Search by caption or ID, select a case, or use **Random sample** to sample the current search results. Drag to orbit, scroll over a model to zoom, and use the shared timeline to compare the same frame.

Motion payloads, SMPL shape corrections, and constant per-sequence floor alignment are retained from the source viewer. No sample exclusions or motion smoothing were added. This page provides qualitative inspection, not additional quantitative evaluation. All runtime assets are local.

Open index.html in the Anonymous GitHub website view. Third-party library license notices are retained.
